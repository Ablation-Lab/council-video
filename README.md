## Preview

```
npm install
npm run dev
```

This opens Remotion Studio in your browser. The `Explainer` composition is the full film. `Scene01` to `Scene10` let you preview one scene at a time.

## Project layout

- `src/timing.ts`: scene order, narration text and durations. Each scene's length comes from its recording, plus a short lead-in, tail and any visual hold. `makeCue('s03')('phrase')` returns the frame where a phrase is spoken in the recording, and the animations use it.
- `src/voiceover.json`: each clip's length and per-word timings, generated by `scripts/align-voiceover.mjs`.
- `src/theme.ts`: colours, fonts and minimum type sizes.
- `src/anim.ts`: easing and fade helpers.
- `src/components/`: the shared scene frame, Generation Tree nodes and edges, narration player, and icons.
- `scripts/review-stills.mjs`: renders evenly spaced stills of a composition to `out/stills/` for visual review, e.g. `node scripts/review-stills.mjs Scene03 --count=12 --sheet` (the sheet tiles them into one image).

## Voiceover

The ElevenLabs originals are `scene01.mp3` to `scene10.mp3` in the project root (some are named `SceneNN.mp3`) and are never modified. To use new recordings, replace those files and run:

```
npm run voiceover
```

This needs a full ffmpeg on PATH. It does two things:

1. `scripts/normalize-voiceover.mjs` writes loudness-normalised copies (-14 LUFS, peaks at or below about -1.5 dBFS) to `public/audio/sceneNN.mp3`. That's the audio the video plays.
2. `scripts/align-voiceover.mjs` finds the pauses in each clip, matches them to the punctuation in `script.md`, and writes per-word timings to `src/voiceover.json`. Scene lengths and every animation cue follow from those timings.

If you change the wording, update `script.md` and the matching narration in `src/timing.ts`, then re-run it. `src/timing.ts` refuses to build if a recording's word count no longer matches its narration.

To check a recording's wording, `scripts/transcribe-windows.ps1` transcribes a WAV with Windows' built-in speech recogniser. It's rough, but good enough to spot changed phrases.
